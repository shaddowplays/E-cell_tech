# E-cell_tech
Technologies Used
HTML5: Semantic markup for structured, accessible content.

CSS3: Vanilla CSS utilizing Flexbox, CSS Grid, and custom CSS variables.

No Frameworks: Built entirely from scratch without libraries like Bootstrap or Tailwind to demonstrate core frontend fundamentals and clean code architecture
Approach & Architecture
Modular Page Structure: The site is separated into four distinct HTML files (index.html, events.html, forge-2026.html, about.html) to establish a clear hierarchy and maintain single-responsibility for each view.

Unified Branding: A single style.css file dictates the visual identity across all pages.
